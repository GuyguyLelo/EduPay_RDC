# Guide : Comment effectuer un paiement (Étudiant)

## Vue d'ensemble

Ce guide explique comment un étudiant peut effectuer un paiement de frais scolaires via la plateforme EduPay RDC.

## Processus de paiement

### Étape 1 : Connexion
1. Accédez à la plateforme EduPay RDC
2. Connectez-vous avec votre email et mot de passe (fournis par votre établissement)
3. Vous serez redirigé vers votre tableau de bord étudiant

### Étape 2 : Consulter les frais à payer
1. Sur votre tableau de bord, vous verrez une section **"Mes Frais à Payer"**
2. Cette section liste tous les frais actifs de votre établissement que vous n'avez pas encore payés
3. Pour chaque frais, vous verrez :
   - Le type de frais (ex: Frais de scolarité, Frais d'inscription)
   - L'année académique
   - Le montant à payer

### Étape 3 : Initier le paiement
1. Cliquez sur le bouton **"Payer"** à côté du frais que vous souhaitez payer
2. Vous serez redirigé vers la page de paiement qui affiche :
   - Les détails du frais (type, établissement, année académique)
   - Le montant à payer

### Étape 4 : Remplir le formulaire de paiement
1. **Numéro de téléphone Mobile Money** :
   - Entrez votre numéro de téléphone Mobile Money
   - Format requis : `+243XXXXXXXXX` (ex: +243900000000)
   - Ce numéro doit être celui associé à votre compte Mobile Money

2. **Opérateur Mobile Money** :
   - Sélectionnez votre opérateur :
     - **M-Pesa** : Pour les comptes M-Pesa
     - **Orange Money** : Pour les comptes Orange Money
     - **Airtel Money** : Pour les comptes Airtel Money

3. Cliquez sur le bouton **"Payer [montant] [devise]"**

### Étape 5 : Confirmer le paiement sur votre téléphone
1. Après avoir soumis le formulaire, vous recevrez une demande de confirmation sur votre téléphone
2. **IMPORTANT** : Vous devez confirmer le paiement sur votre téléphone pour finaliser la transaction
3. La confirmation se fait via votre application Mobile Money ou par SMS selon votre opérateur

### Étape 6 : Vérification et confirmation
1. Après confirmation sur votre téléphone, vous serez redirigé vers la page de succès
2. Si le paiement est en attente, vous pouvez :
   - Cliquer sur le bouton **"Vérifier"** dans votre historique de paiements
   - Attendre quelques instants et rafraîchir la page

### Étape 7 : Télécharger le reçu
1. Une fois le paiement confirmé (statut "Réussi"), vous pouvez :
   - Télécharger le reçu PDF en cliquant sur **"Reçu"** dans votre historique
   - Un email de confirmation sera également envoyé à votre adresse email

## Historique des paiements

Sur votre tableau de bord, vous pouvez consulter :
- **Frais à payer** : Liste des frais en attente de paiement
- **Historique des paiements** : Tous vos paiements avec leur statut :
  - ✅ **Réussi** : Paiement confirmé et validé
  - ⏳ **En attente** : Paiement initié, en attente de confirmation
  - ❌ **Échoué** : Paiement non abouti

## Statuts des paiements

### PENDING (En attente)
- Le paiement a été initié mais n'est pas encore confirmé
- Vous devez confirmer sur votre téléphone
- Vous pouvez cliquer sur "Vérifier" pour mettre à jour le statut

### SUCCESS (Réussi)
- Le paiement a été confirmé et validé
- Vous pouvez télécharger le reçu PDF
- Un email de confirmation a été envoyé

### FAILED (Échoué)
- Le paiement n'a pas pu être effectué
- Vérifiez votre solde Mobile Money et réessayez
- Contactez le support si le problème persiste

## Conseils et bonnes pratiques

1. **Vérifiez votre solde** : Assurez-vous d'avoir suffisamment de fonds sur votre compte Mobile Money
2. **Confirmez rapidement** : Confirmez le paiement sur votre téléphone dès réception de la demande
3. **Conservez vos reçus** : Téléchargez et sauvegardez les reçus PDF pour vos archives
4. **Vérifiez le statut** : Si un paiement reste en "En attente", utilisez le bouton "Vérifier"
5. **Contactez le support** : En cas de problème, contactez l'administration de votre établissement

## Problèmes courants

### Le paiement reste en "En attente"
- **Solution** : Cliquez sur le bouton "Vérifier" dans votre historique
- Si le problème persiste, attendez quelques minutes et réessayez

### Erreur lors de l'initiation du paiement
- Vérifiez que votre numéro de téléphone est correct (format +243XXXXXXXXX)
- Vérifiez que vous avez sélectionné le bon opérateur
- Vérifiez votre connexion internet

### Le paiement a échoué
- Vérifiez votre solde Mobile Money
- Vérifiez que votre compte Mobile Money est actif
- Réessayez le paiement

## Support

- Vérifiez votre email pour les notifications

**Note** : Les paiements sont traités via Flutterwave et les opérateurs Mobile Money en RDC (M-Pesa, Orange Money, Airtel Money). La plateforme prélève automatiquement une commission sur chaque paiement réussi.
